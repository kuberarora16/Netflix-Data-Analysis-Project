Netflix Data Analysis Dashboard – Power BI
📌 Project Overview

This project is an interactive Netflix Data Analysis Dashboard created using Microsoft Power BI. The dashboard provides insights into customer subscriptions, engagement, revenue, content preferences, ratings, and customer demographics.

The goal of this project is to transform raw customer data into meaningful visual insights that can support business reporting, customer analysis, and data-driven decision-making.

📊 Key KPIs
Total Customers: 951
Active Customers: 670
Total Revenue: 7M
Average Rating: 3.76
Average Watch Hours: 44.31
Project Objective

The main objective of this project is to demonstrate how Power BI, DAX, and data visualization can be used to analyze customer behavior and business performance and convert raw data into actionable insights.

📁 Skills Demonstrated

Power BI | DAX | Power Query | Data Cleaning | Data Analysis | Data Visualization | Dashboard Development | KPI Reporting

Short GitHub Description

Netflix Data Analysis Dashboard built using Power BI to analyze customer subscriptions, revenue, engagement, ratings, demographics, account status, payment methods, and content preferences through interactive KPIs, charts, and slicers.
